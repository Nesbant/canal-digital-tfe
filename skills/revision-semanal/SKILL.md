# Revisión semanal (retrospectiva)

## Objetivo
Generar una retrospectiva a partir de lo que realmente está registrado — no de memoria ni de suposiciones. Ver `references/retrospectiva.md` para el formato y las reglas anti-invento.

## Fuentes a consultar
1. Digital Log (cuando exista)
2. Experimentos modificados en el período
3. Aprendizajes (cuando exista)
4. Retro anterior (para no repetir ni perder continuidad)

Mientras Digital Log/Aprendizajes no existan, generar la retro solo con Experimentos + lo que haya en Bitácora Ecommerce TFE, y decir explícitamente qué fuentes faltaron.

## Output esperado

```markdown
# Revisión semanal

## Hechos relevantes
...
## Experimentos
...
## Pendientes
...
## Aprendizajes
...

# Retrospectiva
## ✅ Salió bien
...
## ❌ Salió mal
...
## 🎯 Nos sorprendió
...
## 🚀 Vamos a hacer
...
```

## Procedimiento
1. Leer solo el período correspondiente (no todo el histórico, salvo que se pida explícitamente).
2. Consultar la retro previa para no repetir ni perder continuidad.
3. Detectar eventos y temas recurrentes; agrupar por tema, no por persona.
4. Evitar incluir actividad rutinaria sin relevancia.
5. Crear como Borrador. **Nunca marcar como Presentada automáticamente** — eso lo decide el equipo.

## Flujo humano
Claude genera el borrador → Juan revisa → Valeria consolida → se presenta.
